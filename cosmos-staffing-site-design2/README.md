# Cosmos Staffing Website Prototype

A static HTML/CSS/JS prototype for Cosmos Staffing (Cosmos Services LLC).

## Open locally

Open `index.html` directly in a browser, or run a simple local server:

```bash
cd cosmos-staffing-site
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- Home, About, Staffing & Recruiting, Professional Search, HR & Payroll, Bookkeeping, For Job Seekers, Contact
- Light/dark design tokens with session-persisted toggle
- Sticky condensed header and mobile overlay nav
- Homepage hero, problem visual, bento services grid, scrollytelling stepper, proof/stats, roles marquee, candidate band, final CTA
- Scroll reveals, subtle parallax, count-up placeholders, magnetic buttons, card hover effects
- Reduced-motion fallback
- Simulated Contact form success state

## Content safety

The prototype keeps placeholder claims visible and avoids unsupported claims like Employer of Record, guaranteed compliance, nationwide coverage, executive retained search, certifications, or invented client logos/testimonials.
